Score sheet · Communicate by Tactical Radio

    Measures 4–5 (radio check, 10–20 word message) are voice steps and are not part of this key drill.

    Exam mode

    • One clock for the whole drill: 1:30. It starts when you press Start.
    • No coach, no key highlights, no 7-second bar, no ✓ marks until the end.
    • Set FCTN to load first. Mode SC, power HI, COMSEC PT and CHAN 1 can be set in any order; only the settings have to be right (mode and channel must be set before you load). Fastest: one pass through MENU, CHAN 1 → PWR HI → MODE SC → CMSC PT. Then Press FREQ → Press CLR → Enter 5 digits → Press STO within 7 seconds → Set FCTN to SQ. ON. Using MENU before LD is an order error and a NO-GO. Any other slip can be fixed: go back (to LD if needed), correct it, and finish in SQ ON; only the final settings count.
    • One channel (CH 1). The exam ends when the radio is set to communicate in SC mode, or at 1:30. A NO-GO sends you to Charlie Company.

    Cheat sheet · AN/PRC-119F (RT-1523E ASIP)

    Score-sheet steps and the keys for each (one channel)

    1. Obtained required SC frequencies. The grader gives you the frequency for channel 1.
      • Prepare radio for Single Channel Frequencies loading.
      • Set FCTN to load: knob to LD.
      • Then one pass through MENU (VOL → CHAN → PWR → MODE → CMSC):
      • Set CHAN 1: MENU twice, press 1.
      • Set power to HI: MENU once, CHG twice (LO → M → HI).
      • Set mode to SC: MENU once, CHG twice (FH → FHM → SC).
      • Set COMSEC to PT: MENU once, CHG 3 times (CT → TD → RV → PT).
      The radio starts at the TM defaults (CHAN not 1, PWR LO, MODE FH, COMSEC CT). After LD, these four can be set in any order and only the settings count; following the MENU order is simply the fastest (5 MENU presses). Mode must be SC and CHAN must be 1 before you load. Power and COMSEC don't affect loading. From the COMSEC screen you can press FREQ right away. Missed something, like CHAN 1? Go back (to LD if needed), fix it and load again; only the final settings count.
    2. Load SC frequencies.
      • Press FREQ: FREQ shows what channel 1 holds now.
      • Press CLR: CLR clears the display to -----.
      • Enter 5 digits SC frequencies: 81.000 is 81000.
      • Store SC frequencies. Press STO within 7 seconds: STO; the display blinks once.
    3. Prepare to Communicate.
      • Set FCTN to SQ. ON: knob to SQ ON.
      • Set CHAN to CHAN 1: you are already on it after loading.
      • Communicate in SC Mode.

    Steps 4–5 (radio check, 10–20 word message) are voice steps and are not drilled here. The score sheet allows 5 minutes; this trainer's Exam clock is 1:30.

    Notes

    MENU and CLR share one key. If no key is pressed for 7 seconds, the display times out and drops what you typed.

    FCTN knob: drag it, or tap its right half to turn clockwise and its left half counterclockwise. On a computer you can also type digits, F = FREQ, C or M = MENU/CLR, S = STO.
